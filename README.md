# Modern Full Stack Development, guest lecture at FXEC

Slides and the live-demo code for the guest lecture to II CSE C, Francis Xavier
Engineering College, Tirunelveli, on 9 October 2026.

- `slides.md`  the deck, built with [Slidev](https://sli.dev). `pnpm install && pnpm dev`, then open http://localhost:3030.
- `modern-full-stack-development.pdf`  the same deck as a PDF.
- `demo/`  the todo app with sign up: Spring Boot 4 + React + PostgreSQL, with Docker files to put it on a server. Start with `demo/README.md`; `demo/STEPS.md` is the minute-by-minute plan of the live session.

Homework from the lecture: go to start.spring.io, add Spring Web, Spring Data
JPA and H2, and make `GET /api/todos` return a JSON list. Then rebuild this
whole project from `demo/STEPS.md` over a weekend.
